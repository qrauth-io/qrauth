# Protected domains for the lookalike check (ADR-0007).
#
# A QR destination or link whose host is confusable with one of these
# (UTS #39 skeleton) or close to it (edit distance on skeletons) gets the
# lookalike warning: a warning on create, UNTRUSTED with no auto-continue on
# scan. The listed domains themselves and their subdomains are exempt.
#
# Format: one brand per line, `Display name: domain domain ...`. List every
# official domain of the brand on its line (country domains included): they
# are all exempt for that brand, so a brand's own sites are never flagged as
# lookalikes of each other. Domains are lowercase ASCII (punycode for IDN).
#
# Strict brands, marked `[strict]` after the name: the brand's exact name
# on a TLD that is not listed on its line is a lookalike too (aade.com,
# paypal.xyz). Use it for banks, public services, payment and identity
# providers whose name is distinctive, and list the brand's real country
# domains. Leave names that are ordinary words (wise, chase, alpha, viva,
# crypto, ledger) non-strict: an unrelated site may own them elsewhere.
#
# Wordlike strict brands, marked `[strict wordlike]`: a strict brand whose
# name is also an ordinary word or place (visa, kraken, stripe, santander;
# astynomia, ktimatologio in Greek). They stay strict on other TLDs
# (visa.xyz is a lookalike), but the name as a hyphen token counts only next
# to a phishing keyword (visa-login.com is a lookalike, visa-team.com and
# kraken-games.com are not). Mark a strict brand wordlike when its name
# reads as a word in English or Greek, or names a place.
#
# Multi-tenant domains, where customers choose the subdomain
# (contoso.sharepoint.com), are marked with `@`: only the domain itself (and
# any host listed separately) is the brand's own; a tenant label is checked
# like any registered name, so paypa1.sharepoint.com is a lookalike of
# PayPal. Mark every domain that hands out customer-chosen subdomains.
#
# Policy: brands and services that QR phishing in Greece and the EU imitates
# (Greek banks and public services, payments, logins of the large platforms,
# parcel carriers). Add an entry when a brand is targeted; remove one only
# with a reason in the commit message. Verified QRAuth organizations are
# protected automatically and need no entry here.
