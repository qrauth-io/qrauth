# Python SDK (Discontinued)

The Python SDK (`qrauth` on PyPI) has been discontinued as of 2026-04-16.

There is no maintained Python SDK. From Python, call the [REST API](/api/overview) directly, or use any standard OpenID Connect library with the [OIDC provider](/guide/oidc) for sign-in. Use the [Node.js SDK](/sdk/node) for server-side integration in Node.js, or the [Web Components](/sdk/web-components) for browser-based flows.
